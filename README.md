# SQL-exploratory-data-analysis-project-
This project involves a complex  analysis using window functions, subqueries, and CTEs of big data and generating two full-length reports on customers and products. 
## Questions
1. For Customer Report
-Calculate valuable KPIs:
- recency (months since last order)
- average order value
- average monthly spend
2. For Product Report
-Calculate valuable KPIs:
- recency (months since last sale)
- average order revenue (AOR)
- average monthly revenue
